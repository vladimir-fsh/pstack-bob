# pstack

pstack workflows for Claude Code and Codex, built from
[michael-denyer/pstack-claude](https://github.com/michael-denyer/pstack-claude)
with one addition: the `arena`, `interrogate`, and `thermos` panels can run the
other vendor's model through its CLI. See
[external seats](skills/poteto-mode/references/external-seats.md).

```text
/plugin install pstack --marketplace vladimir-fsh/pstack-bob
```

This folder is generated. Change it through `patches.json` and `overlay/` in
[vladimir-fsh/pstack-bob](https://github.com/vladimir-fsh/pstack-bob).
