# pstack

pstack workflows for Claude Code and Codex. The `arena`, `interrogate`, and
`thermos` panels can run the other vendor's model through its CLI, as
[external seats](skills/poteto-mode/references/external-seats.md).

```text
/plugin install pstack --marketplace vladimir-fsh/pstack-bob
```

Maintained in [vladimir-fsh/pstack-bob](https://github.com/vladimir-fsh/pstack-bob),
which merges Cursor's upstream pstack into this folder.
